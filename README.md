# Mapping Local Livelihood Initiatives in Lebanon

This project was developed during my time at **UN-Habitat** and focuses on visualizing and organizing data related to local livelihood initiatives across Lebanon. The work aimed to support evidence-based planning and decision-making by mapping initiative coverage and distribution by both district and cadaster.

## 📍 Project Overview

This project aimed to map and analyze livelihood initiatives implemented throughout Lebanon, using spatial data and raw activity records from the field. It involved:

- Cleaning and organizing complex, multi-source **raw Excel data**
- Creating **custom shapefiles** at both the **district** and **cadaster** levels
- Connecting each area to information like:
  - Type of initiative (e.g. vocational training, access to market)
  - Donors, implementing partners, and consortiums
  - Beneficiaries: nationality, age group, gender
- Generating maps and visualizations to understand where initiatives were happening and for whom

## 🎯 Objectives

- Provide a spatial understanding of where livelihood support is being delivered.
- Support planners, analysts, and humanitarian stakeholders in identifying gaps and coverage.
- Practice responsible data sharing while showcasing GIS and data wrangling skills.
